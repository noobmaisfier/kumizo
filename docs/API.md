Types, signatures, commands. **No explanations.** For context and rationale, see [`GUIDE.md`](./GUIDE.md).

## Mini-index

- **Services:** `Clock`, `Battery`, `Memory`, `Audio`, `Brightness`, `Mpris`, `Network`, `Bluetooth`, `Compositor`, `Apps`, `Notifications`, `Tray`, `Clipboard`
- **UI:** `TextBuffer`, `TextAction`, `TextStyle`, `text_input`, `text_area`

- **IPC:** `socket_path()`, `Request`, `Response`, `IpcClient`
- **CLI:** `kumizo <cmd>`

Everything lives in the `kumizo-kit` crate, grouped by module. The CLI (`kumizo`) and the reference shell (`kumizo-aurora`) are separate packages.

## Conventions

- `Entity<T>`: GPUI model, created via `cx.new(...)`.
- A service `S` becomes `Entity<S>` by being registered via `Kumizo::service::<S>()`, then retrieved in views via `cx.service::<S>()` (from `ServiceContextExt`).
- `View<T>`: GPUI view, created via `cx.new(...)` returning `Entity<V>` where `V: Render`.
- `Context<T>`: GPUI context, alias `cx` in examples.
- `impl IntoElement`: any displayable GPUI element.
- Services are `'static` and live on the GPUI main thread (they are **not** `Send`/`Sync`); background work runs in spawned tasks that notify through `cx`.
- Methods that trigger a redraw take `cx: &mut Context<Self>` and call `cx.notify()`.
- Borrowed returns (`&str`, `&[...]`) must not escape `render` (E0521). `[&mut]` methods must be called via `entity.update(cx, |s, cx| { …; cx.notify(); })`.

## 1. Core — `kumizo-kit`

### Traits

```rust
pub trait Service: 'static + Sized {
    /// Initialize the service within GPUI's context.
    fn init(cx: &mut gpui::Context<Self>) -> Self;

    /// Apply an action requested through `kumizo service <name> <action> [payload]`.
    /// Runs on the GPUI main thread. Returns `true` when the action was recognised;
    /// unknown actions must return `false`.
    fn ipc_action(
        &mut self,
        cx: &mut gpui::Context<Self>,
        action: &str,
        payload: Option<&str>,
    ) -> bool { false }
}

pub trait IntoWindowView<V: 'static + Render> {
    fn build(self, cx: &mut gpui::App) -> Entity<V>;
}

/// Blanket impl: any closure `FnOnce(&mut App) -> Entity<V>` implements this
/// trait automatically (see `kumizo-kit/src/app.rs`).
/// This is what makes `.window(config, |cx| cx.new(MyView::new))` work.
impl<F, V> IntoWindowView<V> for F
where
    F: FnOnce(&mut gpui::App) -> Entity<V>,
{
    fn build(self, cx: &mut gpui::App) -> Entity<V> {
        self(cx)
    }
}

pub trait ServiceContextExt<V: 'static> {
    fn service<S: Service>(&mut self) -> Entity<S>;
    fn try_service<S: Service>(&mut self) -> Option<Entity<S>>;
}

pub trait AppContextServiceExt {
    fn service<S: Service>(&self) -> Entity<S>;
    fn try_service<S: Service>(&self) -> Option<Entity<S>>;
}
```

### Compositor (`kumizo_kit::compositor`)

Detects Hyprland, Sway (and i3) or Niri automatically. Hyprland instances using
the Lua config provider (0.55+) are driven through its Lua dispatcher API
(`hl.dsp.*`); instances still on `hyprlang` use the legacy dispatchers. The
active style is read from `j/status` (`configProvider`) with a `j/version`
fallback. Commands are sent without a trailing newline and the write half is
shut down, exactly like `hyprctl`.

```rust
pub struct Compositor;
pub enum CompositorKind { Sway, Hyprland, Niri, Fallback }

pub struct Workspace {
    pub id: i32,
    pub name: String,
    pub address: String,     // backend selector: "3", "web", "special:magic", "name:special:x"
    pub is_active: bool,
    pub is_urgent: bool,
    pub window_count: usize,
    pub monitor: String,
}
pub struct Monitor {
    pub id: i64, pub name: String, pub description: String,
    pub width: i32, pub height: i32, pub refresh_rate: f64,
    pub x: i32, pub y: i32, pub scale: f64,
    pub focused: bool, pub disabled: bool,
    pub active_workspace: String, pub active_workspace_name: String,
    pub special_workspace: Option<String>, pub special_workspace_name: Option<String>,
}
pub struct AppWindow { pub id: i64, pub title: String, pub class: String, pub workspace_id: i32, pub workspace_name: String, pub is_focused: bool }
pub struct ActiveWindow { pub title: String, pub class: String, pub workspace_id: i32 }

impl Service for Compositor {
    fn init(cx: &mut Context<Self>) -> Self;
    fn ipc_action(&mut self, cx: &mut Context<Self>, action: &str, payload: Option<&str>) -> bool;
}

impl Compositor {
    pub fn kind(&self) -> CompositorKind;
    pub fn workspaces(&self) -> &[Workspace];
    pub fn active_workspace_id(&self) -> i32;
    pub fn active_workspace(&self) -> Option<&Workspace>;
    pub fn active_workspace_is_special(&self) -> bool;
    pub fn active_window(&self) -> Option<&ActiveWindow>;
    pub fn windows(&self) -> &[AppWindow];
    pub fn monitors(&self) -> &[Monitor];
    pub fn focused_monitor(&self) -> Option<&Monitor>;

    pub fn switch_workspace(&mut self, id: i32);
    pub fn try_switch_workspace(&mut self, id: i32) -> anyhow::Result<()>;
    pub fn switch_workspace_address(&mut self, address: &str) -> anyhow::Result<()>;
    pub fn focus_window(&self, con_id: i64);            // Hyprland address, Sway node, Niri id
    pub fn try_focus_window(&self, con_id: i64) -> anyhow::Result<()>;
    pub fn close_window(&self);                          // active window
    pub fn close_window_id(&self, con_id: i64);
    pub fn toggle_floating(&self, con_id: Option<i64>) -> anyhow::Result<()>;
    pub fn toggle_fullscreen(&self, con_id: Option<i64>) -> anyhow::Result<()>;
    pub fn move_window_to_workspace(&self, con_id: Option<i64>, workspace: &str, follow: bool) -> anyhow::Result<()>;
    pub fn focus_monitor(&self, name: &str) -> anyhow::Result<()>;
    pub fn toggle_special_workspace(&self, name: &str) -> anyhow::Result<()>; // Hyprland only
    pub fn reload_config(&self) -> anyhow::Result<()>;
}
```

`Workspace::id` is a UI handle. Numbered workspaces keep the compositor number;
named and special workspaces get a stable negative id. Always pass
`Workspace::address` (via `switch_workspace(id)`, which resolves it) rather than
the raw id when talking to the compositor: Hyprland needs `3`, `web` or
`special:magic`, and a named workspace called `special:x` is stored as
`name:special:x` so it is not confused with the real special workspace.
`Workspace::is_special()` reports Hyprland scratchpads.

Events covered: workspace create/destroy/rename/move, monitor hotplug, window
open/close/move/title/focus, floating/fullscreen/pin/minimize changes, urgency
and config reload. State-changing events trigger an authoritative re-query
instead of replaying deltas, and the event socket reconnects with exponential
backoff with a full resync after every reconnect.

`kumizo service compositor <action> [payload]` accepts: `switch_workspace`,
`focus_window`, `close_window`, `toggle_floating`, `toggle_fullscreen`,
`move_window`, `focus_monitor`, `toggle_special`, `reload_config`.

### Minimal usage example

Register a service in `main()` and read it in a view:

```rust
// 1. Register (in main)
Kumizo::new()
    .service::<Battery>()
    .window(
        LayerWindow::new("bar")
            .layer(Layer::Top)
            .anchor(Anchor::TOP | Anchor::LEFT | Anchor::RIGHT)
            .height(32.0),
        |cx: &mut gpui::App| cx.new(BatteryView::new),
    )
    .run();

// 2. Read in the view
struct BatteryView { battery: Entity<Battery> }

impl BatteryView {
    fn new(cx: &mut Context<Self>) -> Self {
        Self { battery: cx.service::<Battery>() }
    }
}

impl Render for BatteryView {
    fn render(&mut self, _window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        let pct = self.battery.read(cx).percent();
        div().child(format!("{}%", pct))
    }
}
```

### Text in GPUI elements

GPUI allows `.child(String)` and `.child(&'static str)` directly — no `Text` wrapper needed. For formatted strings, prefer `.child(format!(...))` over looking for a `Text::new(...)` that does not exist in the public API.

## 4. Security — `kumizo_kit::pam`

Minimal Linux-PAM password check, hand-written FFI against `libpam.so`. No `bindgen`/`libclang` dependency.

```rust
/// Outcome of verifying a password against a PAM service.
pub enum AuthError {
    /// The password was wrong.
    WrongPassword,
    /// The account is unknown to the auth backend.
    UnknownUser,
    /// The account is locked out after too many failures.
    LockedOut,
    /// The authentication backend could not be reached.
    Unavailable,
    /// Any other PAM error, with the raw status code.
    System(c_int),
}

impl AuthError {
    /// Message safe to display to the user at a lock screen.
    /// Vague on purpose: never leaks whether an account exists.
    pub fn user_message(self) -> &'static str;
}

/// Check `password` for `user` against `service` (e.g. `"swaylock"` or `"login"`).
/// Synchronous and blocking — call off the UI thread.
pub fn verify(service: &str, user: &str, password: &str) -> Result<(), AuthError>;
```

`verify` wipes its copy of the secret before returning. The `strdup` copies handed to PAM are freed by PAM itself.

```rust
        const LEFT = 1 << 2;
        const RIGHT = 1 << 3;
        // Convenience: TOP_BAR, BOTTOM_BAR, LEFT_BAR, RIGHT_BAR, FULLSCREEN.
    }
}
impl Default for Anchor { /* TOP | LEFT | RIGHT */ }
impl std::ops::BitOr for Anchor { type Output = Anchor; }

pub struct Margins { /* top, right, bottom, left */ }
impl Margins {
    pub const fn zero() -> Self;
    pub const fn all(val: i32) -> Self;
    pub const fn symmetric(h: i32, v: i32) -> Self;
    pub const fn new(top: i32, right: i32, bottom: i32, left: i32) -> Self;
}
```

## 7. CLI — `kumizo` (binary `kumizo`, package `kumizo-cli`)

```
kumizo <COMMAND> [OPTIONS]

COMMANDS:
    ping                        Check if the shell is responding
    status                      Display uptime, windows, and services
    toggle <WINDOW_NAME>        Toggle visibility of the specified window (e.g. "dock")
    show <WINDOW_NAME>          Show/open the specified window
    hide <WINDOW_NAME>          Hide/destroy the specified window
    reload                      Re-render every registered window
    service <NAME> <ACTION>     Send a command to a registered service
                                Example: kumizo service audio toggle_mute
                                Example: kumizo service mpris next

OPTIONS:
    -h, --help                  Print this help information

Kumizo is single-instance: there is exactly one socket,
$XDG_RUNTIME_DIR/kumizo.sock (override with $KUMIZO_SOCKET).

EXAMPLES:
    kumizo status
    kumizo toggle dock
```

```bash
cargo install --locked kumizo
```

## 8. Feature flags & workspace

### Feature flags

| Feature | Default | Contents |
|---|---|---|
| `app` | ✅ | `Kumizo` builder, registry, animation, prelude; implies all the modules below |
| `layer-shell` | ✅ | real `wlr-layer-shell` surfaces (implies `layer-shell-variant`) |
| `services` | ✅ via `app` | Clock, Battery, Audio, MPRIS, Network, Tray, Bluetooth, Memory… |
| `compositor` | ✅ via `app` | Sway / Hyprland / Niri IPC |
| `ipc` | ✅ via `app` | protocol, client, server, `WindowControl` |
| `ext` | ✅ via `app` | layer-shell wrappers (pulls `gpui`) |
| `ui` | ✅ via `app` | text input primitives (pulls `gpui`) |
| `pam` | ❌ | `pam::verify` Linux-PAM check |
| `full` | alias | same as `default` today (`app` + `layer-shell`) |
| `layer-shell-variant` | via `layer-shell` | internal switch read by `kumizo_kit::ext` |

A CLI that only talks to the socket uses `default-features = false, features = ["ipc"]`
and never compiles GPUI, wgpu or zbus (`cargo tree -p kumizo | grep gpui` → empty).

### Packages & modules

| Package | Role |
|---|---|
| `kumizo-kit` | the SDK — everything below, behind feature flags |
| `kumizo` | the `kumizo` CLI (feature `ipc` only) |
| `kumizo-aurora` | reference shell: `aurora` + `aurora-lockscreen` |

| `kumizo_kit::` module | Feature | Role |
|---|---|---|
| `app` | `app` | `Kumizo` builder, registry, animation, prelude |
| `ext` | `ext` | GPUI Wayland layer-shell traits and wrappers |
| `services` | `services` | Async system services (Clock, Battery, Audio, MPRIS…) |
| `compositor` | `compositor` | Compositor IPC (Hyprland, Sway, Niri) |
| `ipc` | `ipc` | UNIX-socket daemon protocol + server |
| `ui` | `ui` | Headless UI primitives |
| `pam` | `pam` | Minimal Linux-PAM check, no bindgen/libclang |

Workspace dependencies are pinned: `gpui-pre =0.3.9`, `gpui-pre-platform =0.3.9`. Exactly one `gpui-pre` version in the whole dependency graph.
